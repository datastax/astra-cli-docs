= astra dotenv

[source,shell]
----
astra dotenv [-qV] [--no-input] [--[no-]spinner] [--color[=WHEN]] [--dump-logs
             [=FILE]] [-h[=all]] [-o=FORMAT] [COMMAND]

----


Easily create and update your .env files __(beta)__



== Subcommands

* xref:astra-dotenv-write.adoc[astra dotenv write]
* xref:astra-dotenv-print.adoc[astra dotenv print]
* xref:astra-dotenv-list-keys.adoc[astra dotenv list-keys]


== Options


=== Common Options
`-h`, `--help`:: Show this help message and exit.
`-o`, `--output`:: One of: human, json, csv
`-V`, `--verbose`:: Enable verbose logging output
`-q`, `--quiet`:: Only output essential information
`--spinner`:: Enable/disable loading spinners
`--no-input`:: Don't ask for user input (e.g. confirmation prompts)
`--color`:: One of: auto, never, always
`--dump-logs`:: Write all logs to an optionally specified file
